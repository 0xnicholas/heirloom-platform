# 接入与部署

> **范围**：双轨接入与接入端点、CSV 归客户端 CLI、导入批次审计、外部同步器模式、部署拓扑（compose 双形态）、引擎 schema 迁移、升级 runbook 与配置面。
> **不含**：本体演化语义与本体 DDL 平面（[60](60-evolution.md)）；接入端点/push 线上编码（[30](30-api.md)）；引擎写入通道事务原语（[40](40-engine.md)）。
> **素材**：[ADR-0005](../adr/0005-data-ingestion-deployment.md)（#11 决议全文）；ADR-0004（服务账号/PAT、超管引导）、ADR-0002（写入通道、水位线）、ADR-0007（迁移平面分立）。
> **待落位**：无。
> **验收线**：深规格（[#13](https://github.com/0xnicholas/heirloom-pro/issues/13) 决议：逐条规范性陈述、示例内嵌、总表归附录）

## 1. 定位：双轨接入

| 轨 | 路径 | 语义 |
|---|---|---|
| 常规写入 | 动作 API（[20](20-actions.md)） | 语义层唯一写路径；校验/权限/审计挂动作边界 |
| 批量导入 | 接入端点（本章） | 引擎写入通道的管理面暴露；不经动作 |

- 接入端点**不属**语义层写路径（ADR-0003 表述精化）：它是引擎写入通道在管理 API 面的暴露；动作仍是语义层唯一写路径。
- **被否**：仅动作 API 接入（大数据集受动作语义与 1000/批双重约束，管道场景不可用）；开放对象直写进公共语义面（打破唯一写路径，权限/审计挂点重开）。

## 2. 接入端点（管理面批量写入口）

- 调用主体 = **服务账号**（与用户同构，[50](50-security.md) §2）；PAT 认证（Bearer）；接入授权由超管经管理面授予。
- **必须**复用引擎写入通道（[40](40-engine.md) §8）：单请求单事务、批量 ≤1000 对象、任一条违约束 → 整批回滚 + 违规条目清单；对象与链接写入同请求同事务。
- Postgres 原生约束照常承担（required/unique/`CHECK`/外键，[40](40-engine.md) §2–§4）。
- **不得**触发动作语义：无 `execute`、无 `ValidationFailed`、无动作审计——审计以导入批次形态落账（§4）。
- 行级谓词不影响接入（写路径本无读过滤，[50](50-security.md) §5）。
- 请求/响应形状、违规条目清单格式归 [30](30-api.md)（管理面 `/v1/admin/*` 之下）。

## 3. CSV 归客户端 CLI

- 服务端**不得**接受 CSV 解析与文件上传；批量面**必须**保持「一个批量 JSON 端点」。
- `heirloom import` 类 CLI 工具承担转换：列映射、编码、错误报告全部在客户端完成后调接入端点。

```bash
heirloom import employees.csv --type employee   # 参数示意；转换后调接入端点
```

- **被否**：服务端 CSV 导入（上传语义、列映射 DSL、部分失败报告全套进规格，规格面翻倍）。

## 4. 导入批次审计

每个接入端点请求**必须**落**恰好一条**「导入批次」审计条目（与动作条目同库同表家族，[20](20-actions.md) §10）：

| 字段 | 内容 |
|---|---|
| 主体 | 服务账号 + token id |
| 时间 | 时间戳 |
| 请求 id | 请求标识（与响应回执一致） |
| 操作计数 | 逐类型 create / modify / delete 计数 |
| 来源标记 | 调用方自报的来源（如 `hr-sync`） |

```jsonc
// 审计日志 · 导入批次条目（示意）
{ "kind": "import-batch", "subject": "svc:hr-sync", "requestId": "req_01H…", "at": "2026-08-19T…",
  "counts": { "employee": { "create": 984, "modify": 16 } }, "source": "hr-sync" }
```

- **不得**记逐对象明细：百万行导入 = 百万审计行，首批导入即可拖垮部署；批次级足够定位责任。
- 整批回滚的请求照落条目，操作计数为 0（审计 = 治理轨迹，「试过灌」本身可见；normative 注记）。
- 查询：管理面只读端点，复用引擎过滤包（[30](30-api.md)）；v1 不主动清理（同动作审计）。
- **被否**：全量逐对象审计（成本随数据量线性胀）；不审计（治理轨迹开洞）。

## 5. 外部同步器 = 模式级

v1 只**描述**同步器模式，**不留**插件/框架接口位：

| 维度 | 模式 |
|---|---|
| 形态 | 外部进程（调度/断点/背压自管） |
| 认证 | 服务账号 + PAT（[50](50-security.md) §4） |
| 写入 | 调接入端点（§2） |
| 增量读 | 水位线 + 游标增量拉取（`updated_at` 轮询，[40](40-engine.md) §7） |

- 删除不可轮询（无墓碑快照，[40](40-engine.md) §7 已知限制）——同步器的删除对账策略属外部进程自理。
- 理由（normative 注记）：同步器的价值在托管运行；无实现的接口位是无背书的契约面。模式级描述已足够外部系统对齐。
- **被否**：留接口位（要承诺运行时语义，仿逻辑支柱先例不成立——逻辑的接口位是只读查询形状）；完全不提（接入端点文档缺主要使用场景）。

## 6. 部署拓扑：compose 双形态

```yaml
# docker-compose.yml（零配置默认，摘录）
services:
  app:
    image: heirloom
    environment:
      DATABASE_URL: postgres://heirloom:${PGPASSWORD}@postgres:5432/heirloom
    depends_on: [postgres]
  postgres:
    image: postgres   # 具体版本锁定随发布定
```

- docker-compose 起 **app + postgres 两服务** = 零配置默认；app **只读** `DATABASE_URL`。
- `DATABASE_URL` 指外部 Postgres（自建/托管）= **同等正式支持**——同一抽象覆盖两形态。
- 单节点，无 HA（多租户 SaaS 与 HA → v2 边界外，[90](90-appendix.md)）。
- **被否**：仅 compose 内嵌（托管 PG 用户无官方路径）；仅外部 PG（开箱即用受损）。

## 7. 引擎 schema 迁移

- app 启动时**自动**检查并执行引擎 schema 迁移；**必须**以 advisory lock 防并发（多副本/重启竞态）。
- **必须**提供 `migrate-only` 入口（CLI / compose 服务），供迁移账号与运行账号分离的收紧部署手动执行——运行账号可不持 DDL 权限。
- 迁移**只向前**，**不支持降级**（与升级 runbook 一致，§8）。
- 迁移对象 = 引擎系统表，与本体 DDL 平面分立（[60](60-evolution.md) §1）。
- **被否**：仅独立迁移步骤（升级多一步，忘跑即崩）；仅启动自动无逃生门（运行账号须持 DDL 权限，收紧部署无路径）。

```yaml
# 迁移/运行账号分离（摘录）
services:
  migrate:
    image: heirloom
    command: ["heirloom", "migrate-only"]   # 迁移账号持 DDL
  app:
    image: heirloom                          # 运行账号无 DDL 权限
```

## 8. 升级 runbook 与配置面

升级流程（runbook 级，进官方文档）：

1. 停旧版 app；
2. `pg_dump` 备份；
3. 换镜像启动——引擎迁移随启动自动完成（或先跑 `migrate-only`）。

- 规格**不得**自带 backup/restore 命令（pg_dump 是 Postgres 生态标准，无需重造）；无降级路径。
- 部署配置**必须**仅环境变量（12-factor）：`DATABASE_URL`、首超管引导（[50](50-security.md) §3）、动作事务超时（[20](20-actions.md) §6）等；**不得**引入配置文件面。
- 本体**不得**作为部署物：唯一入口 = CLI push（[60](60-evolution.md)）——演化无需重启。文件挂载启动加载、挂载+推送双轨均被否（优先级/冲突语义额外规格面）。

## 9. 已知限制与 v2（详见 [90](90-appendix.md)）

导入不记逐对象审计明细；删除不可轮询（承 [40](40-engine.md)）；无降级路径；单节点无 HA；同步器无托管运行时。
