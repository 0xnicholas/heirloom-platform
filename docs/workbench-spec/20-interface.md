## 1. 外壳总览（裁决 C 定稿）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：术语 N · 已判 M · 链接 K · 草稿变更 X ·（右）flash 消息  │
├───────────┬──────────────────────────────────────┬───────────┤
│ 暗色词汇流 │        中央图谱（谈话主角）           │  节点详情  │
│ （侧栏）   │   节点=类型 · 边=链接+基数+required   │  （抽屉，  │
│ 倒词/轻标记│   草稿增量=虚线绿框                  │  点击滑出）│
│ 过滤搜索   │   pan / zoom / 拖拽摆位              │           │
│           ├──────────────────────────────────────┴───────────┤
│ 生成草稿 → │        草稿底部抽屉（双层预览，生成时展开）        │
└───────────┴──────────────────────────────────────────────────┘
```

- 四区常驻关系（normative）：词汇流与图谱**必须**同屏常驻（加词不离开画布——不打断原则，[10](10-workshop.md) §1）；详情抽屉与底部抽屉为**滑出层**，展开时图谱**必须**仍至少部分可见（草稿抽屉展开时图谱主角地位不丧失）。
- 被否形态（#21 全档存档）：A 步进三幕、B 工作台三区（prototype 分支可回看）；C 的三屏依据 = 三幕（[10](10-workshop.md) §3）。

## 2. 暗色词汇流侧栏（倒词屏）

- **暗色**呈现（不与主画布抢注意力；谈话主角在中央）。
- 交互：输入框回车入池（默认标「待定」）；逐条 chips 轻标记 名/动/待定（点击循环）；粘贴多行 = 按行切分入池（[10](10-workshop.md) §2.1）。
- 分组：按标记着色分组（名词/动词/待定三组，色义见 §6）；**待定永远合法**——UI **不得**出现催促判定的强制态。
- 过滤搜索框常驻顶部（防重复造词；同义词合并入口挂搜索结果，[10](10-workshop.md) §2.2）。
- 底部固定「生成草稿」按钮 → 触发 [30](30-drafting.md) 流程并展开草稿抽屉。
- 字号：词项 ≥14px、暗底对比 ≥4.5:1（投影要求见 §6）。

## 3. 中央注册表派生图谱（谈话主角）

### 3.1 节点

| 元素 | 规格 |
|---|---|
| 对象类型节点 | 圆角矩形（rx≥12），主标 `displayName`（中文）、副标 `apiName`；点击 → 详情抽屉（§4） |
| struct | **不上画布**（无身份、不可链接）——在宿主节点的详情抽屉属性区呈现；避免「可链接」的视觉误导 |
| 草稿新增节点/属性 | **虚线绿框**（区别于注册表现状实线框）；节点角标 `⇠ 草稿` |
| 草稿文件节点 | 独立小节点标 `ontology/<域>.ts ⇠ untracked`，连到其所含类型的草稿节点 |

- 节点由**注册表派生**（求值视图，[40](40-eval-channel.md) §4）——**不得**从源码文本解析。

### 3.2 边（链接）

| 元素 | 规格 |
|---|---|
| 现状链接 | 实线；边标注 `基数 链接名`（如 `1:N employees`）；required 加 `*` 后缀 |
| 草稿链接 | 虚线绿；标注同格式 + `⇠ 草稿` |
| 方向 | 声明方 → 对端（箭头）；基数标注以声明方视角 |

### 3.3 手势与布局

- pan / zoom / 拖拽摆位（reactflow 承载，[50](50-stack.md) §1）；**手动布局即工作坊信息**：节点坐标持久化进工作簿（[60](60-data.md)），重开即还原（W8）。
- v1 **无自动排布**（力导向/自动分层 → v2，[90](90-appendix.md)）。
- 多选/框选 v1 不要求；单节点拖拽**必须**流畅（投影场景下顾问当众摆位）。

## 4. 节点详情抽屉（判定屏）

- 触发：点击图谱节点从右侧滑出；再点他节点切换内容；Esc/关闭钮收起。
- 内容三段：
  1. **判定问句区**：承载规则树步进（[10](10-workshop.md) §4）——一屏一问、选项封闭（三戒之二）；底部常驻「← 上一步」与「待定」出口（三戒之一）。
  2. **属性区**：节点属性清单（标注 unique/enum/数组/⇠ 草稿）；struct 属性展开为嵌入形状。
  3. **快捷件**：`+ string` / `+ decimal` / `+ enum` 加属性按钮（附灯预览：点击即显示该属性将落的档位，[30](30-drafting.md) §4）。
- 快捷件能力边界（normative，联动 [30](30-drafting.md) §2）：对**草稿节点**（本会话未贴回的自产草稿所含类型）→ 直接进草稿块；对**既有节点**（已在仓库注册表中的类型）→ **不得**直接改写；呈现「手工变更指引卡」（生成建议与档位分析，不生成代码——v1 已知限制，[90](90-appendix.md)）。
- 判定完成 → 结尾**块摘要预览**（三戒之三）：将生成的 DSL 块人类语言摘要，确认后入草稿。

## 5. 草稿底部抽屉（双层预览屏）

- 触发：生成草稿时**自动展开**；可收起（图谱仍可见）；再生成时刷新。
- 结构（双层，#17/#20 决议）：

| 层 | 内容 | 受众 |
|---|---|---|
| 主层 | **结构化变更卡**：逐条 人类语言标题 + 档位灯 🟢🟡🔴 + 档位理由（如「自动档——加可空列，不动存量」） | 客户确认 |
| 次层 | 折叠的**增量代码预览**（纯新增行，无删除噪音；diff 呈现见 [30](30-drafting.md) §9） | 顾问 |

- 尾部：git 三行贴回指引 + 落点文件名（[30](30-drafting.md) §8）。
- 「可贴回」按钮：**红灯锁死**（存在拒绝档条目即 disabled，文案「🔴 存在拒绝项——不可贴回」；无红即亮「✅ 可贴回」，黄档警示放行——档位语义见 [30](30-drafting.md) §6）。

## 6. 颜色语义与投影可读性（normative 数值）

- **投影场景**（3 米外可读，#17 实证「词表投影即主场」）：
  - 图谱节点主标 ≥20px、边标注 ≥14px（zoom 100% 基准）；节点最小 160×56px。
  - 变更卡标题 ≥18px、正文 ≥14px；词汇流词项 ≥14px。
  - 前景/背景对比 ≥4.5:1；暗色侧栏与亮色画布的亮度差**应当**明显（注意力分层）。
- **颜色不单独承载语义**（色弱/投影偏色）：三档灯**必须**同时带图符与文字（🟢 自动 / 🟡 数据校验 / 🔴 拒绝）；词汇流轻标记同规则（名/动/待定 = 色 + 字符 chip）。
- 草稿绿（虚线/绿框）**必须**与三档灯绿语义可区分（前者=「尚未生效」，后者=「自动档安全」）——用线型+角标区分，不共用同色同形。

## 7. 交互状态机

### 7.1 抽屉开合（全局）

```
图谱独占 ──点击节点──▶ 详情抽屉开 ──点他节点──▶ 切换内容
   ▲                     ││                        │
   │◀──Esc/关闭──────────┘│                        │
   │◀──收起（图谱主角还原）│                        │
   │                      ▼ 生成草稿
   │◀────────────── 草稿抽屉开（详情抽屉让位收起）
```

- 约束：详情抽屉与草稿抽屉**不同时**展开抢画布（一次一个滑出层；草稿优先）。

### 7.2 节点状态

```
待判定（词汇流内）──第一幕判定──▶ 已判定（图谱出现节点）
已判定 ──重访修改──▶ 判定中（重问受影响项，[10](10-workshop.md) §3）
任意 ──入草稿──▶ 草稿态（虚线绿框，未贴回）
草稿态 ──贴回──▶ 注册表现状（实线；重新求值后生效，[40](40-eval-channel.md)）
```

### 7.3 草稿抽屉态（联动 [30](30-drafting.md) §10）

`收起 ⇄ 展开中 ⇄ 预检通过（无红·可贴回亮）/ 预检有红（锁死）`——状态由预检结果驱动，UI 不另行判断。

## 8. 错误与边界清单

| 情形 | 行为 |
|---|---|
| 仓库无本体（extractor 空注册表） | 正常态：图谱空、首推第一幕；不报错（绿地工作坊） |
| extractor 求值失败（现状侧） | 顶栏警示「现状求值失败：〈定位〉」；图谱冻结展示上次成功视图；草稿生成**不得**进行（预检② 失去基准） |
| 草稿预检② 求值失败 | 错误定位回传至变更卡（红），锁可贴回（[30](30-drafting.md) §5） |
| 节点数过多 | **应当**设软上限建议（投影可读性考量；具体值随实现定，规格锁「存在建议」） |
| 浏览器误关 | 无损——工作簿恢复（[60](60-data.md) §5） |

## 9. 已知限制与 v2（详见 [90](90-appendix.md)）

无自动排布；既有节点属性快捷件只出指引卡；多选批量判定缺席；颜色方案未做实测校准（#17 列 3 项待验证，实现期实测）。
